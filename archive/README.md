# archive

Historical code, kept for reference only. Nothing here is maintained, tested, imported by the package, or covered by the project's compatibility promises.

- `argdeclare.py` — the original [ActiveState recipe](http://code.activestate.com/recipes/576935-argdeclare-declarative-interface-to-argparse) that `argdec` grew out of. It shows the core idea in about 100 lines, without the hierarchy support, validation, error handling or type annotations that came later.

For the maintained implementation, see `argdec.py` in the root of the project.
